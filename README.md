The funniest toaster error message, deadpan and short, written for the make.fun bounty.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Error: toaster refused to brown both sides, citing creative differences and a strict no-crumb policy.
```
